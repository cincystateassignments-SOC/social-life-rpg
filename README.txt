SOCIAL LIFE — QUEEN CITY BUILD

This is a rebuilt responsive browser RPG prototype.

FILES
index.html — interface
style.css — full-screen desktop/mobile layout
game.js — scrolling world, pixel-art renderer, dialogue, quests, menus, saving

GITHUB PAGES UPDATE
1. Extract this ZIP.
2. In the existing social-life-rpg repository choose Add file > Upload files.
3. Upload index.html, style.css, and game.js, replacing the existing files.
4. Commit changes.
5. Wait for the GitHub Pages deployment to finish.
6. Open the existing Pages URL and use Ctrl+Shift+R once if the old build is cached.

CONTROLS
Desktop: WASD / arrow keys to move; Space / Enter to interact.
Mobile: on-screen directional pad and A button.

NOTES
- The world is now Queen City.
- The camera follows the player instead of displaying the whole city at once.
- Journal, People, Concepts, Character, and Help are game menus rather than permanent side panels.
- People populate as the player encounters them.
- Portraits are deliberately low-resolution pixel portraits rather than painterly illustrations.
